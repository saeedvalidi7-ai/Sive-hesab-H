# سیوا حساب

برنامه فارسی راست‌چین برای مدیریت فروش، فاکتور و انبار. این مخزن شامل نسخه وب و تنظیمات اولیه برای بسته‌بندی اندروید با Capacitor است.

## ساخت APK از GitHub

1. همه فایل‌های داخل این پوشه را در ریشه مخزن GitHub خود بارگذاری کنید.
2. در مخزن به زبانه **Actions** بروید.
3. گردش‌کار **Build Siva Hesab APK** را انتخاب کنید و **Run workflow** را بزنید.
4. پس از موفقیت، اجرای گردش‌کار را باز کنید و از بخش **Artifacts** فایل `siva-hesab-debug-apk` را دانلود کنید.
5. ZIP دانلودشده را استخراج کنید تا `app-debug.apk` را ببینید.

این خروجی APK آزمایشی (debug) است و برای انتشار رسمی فروشگاه‌ها باید نسخه release امضاشده ساخته شود.

## نکات

- برای ساخت از GitHub Actions به نصب محلی Android Studio نیاز نیست.
- اطلاعات برنامه در نسخه فعلی در حافظه محلی مرورگر/برنامه نگهداری می‌شوند؛ از نسخه پشتیبان منظم استفاده کنید.
- پیش از استفاده عملیاتی، برنامه را روی چند دستگاه آزمایش و روند پشتیبان‌گیری/بازیابی را بررسی کنید.
